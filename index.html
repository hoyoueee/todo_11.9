YOCO 的核心并不是把 KV 向量压得更小，而是改变 KV 的所有权： self-decoder 生成一份 global KV，cross-decoder 的 13 层只保留各自的 Q。

YOCO-3B

一份 K̂ / V̂，被 13 层读取

self-decoder 输出 X¹³ 后只做一次 K/V 投影；cross-decoder 每层只做 Q 投影与 cross-attention。

V4.1-Flash

40 层切成 20 层 causal encoder + 20 层 decoder。H20 是 encoder 的最终 hidden，decoder 读取由它派生的 compressed KV。

Self-Decoder：常数缓存

self-decoder 的目标不是产生最终 logits，而是把整段序列编码成 X¹³。它使用 efficient attention（gRet 或 SWA）， 因此每层只保留 常数大小 的 state，而不是 [B,S,·] 的历史 KV。

gRet 的投影与 reshape

gRet 的 recurrent form。state 只与 head 数、head_dim 有关，不随 S 增长。
为什么是 O(1)

recurrent state 的形状是 [B, Hself, Dh, Dh]。 序列每增加一个 token，只更新这个固定张量；不会追加 [B,S,·] 的历史。

SWA 版本

如果配置了 sliding_window，self-decoder 改用 SWA。 每层只保留最近 C=128 个 token 的 K/V：

Kswa, Vswa : [B, C, Hself, Dh] C = 128
同样不随完整 S 增长；与 cross-decoder 的 global KV 是两套不同的 cache。

kernel/gate_recurrent.pyrecurrent_gate_retention
def recurrent_gate_retention(q, k, v, g, incremental_state):
    bsz, num_head, _, key_dim = q.shape
    k *= key_dim ** -0.5

    # g 是 log decay，取 exp 后得到 γ_n
    g = g.view(bsz, num_head, 1, 1).float().exp()

    # 当前 token 的 K_n^T V_n
    kv = k.transpose(-1, -2) * v          # [B,H,Dh,Dh]

    if "last_hidden_state" in incremental_state:
        prev_kv = incremental_state["last_hidden_state"]
        kv += prev_kv * g.to(prev_kv.dtype)  # S_n = γ_n S_{n-1} + K_n^T V_n

    incremental_state["last_hidden_state"] = kv

    # O_n = Q_n S_n
    o = q @ kv
    return o

这段代码同时说明了 gRet 的 cache 形状：kv 就是 [B,H,Dh,Dh]，每层一份、递归更新。 它不是“没有 cache”，而是 cache 的序列维度被压成了固定 state。

SWA 版本的 cache 则是 ring/window 结构： prev_key / prev_value : [B,C,Hself,Dh]。 两者都属于 self-decoder 的常数缓存，不参与 cross-decoder 的 global KV 共享。

    def __init__(self, args, checkpoint_activations=False):
        super().__init__()
        self.args = args

        # 关键：SelfDecoder 内部创建 L/2 个普通 DecoderLayer
        layers = [
            DecoderLayer(args, is_cross_layer=False)
            for idx in range(args.n_layers // 2)
        ]
        if checkpoint_activations:
            layers = [checkpoint_wrapper(layer) for layer in layers]
        self.layers = nn.ModuleList(layers)

        self.head_dim = args.dim // args.n_self_heads
        self.block_size = 256
        self._precomputed_freqs_cis = None

    def build_rel_pos(self, x, start_pos):
        ......

    def get_index_mask(self, x, length, pad_length):
        # prefill 时标记哪些位置是 padding
        return torch.arange(pad_length, device=x.device) >= length

    def forward(self, x, incremental_state=None,
                is_prefilling=False, start_pos=0):
        # gRet 的 chunkwise 实现要求 prefill 长度是 256 的倍数
        if (is_prefilling and x.size(1) % self.block_size != 0
                and self.args.sliding_window is None):
            padding_len = self.block_size - x.size(1) % self.block_size
            x = F.pad(x, (0, 0, 0, padding_len), value=0)
        else:
            padding_len = 0

        if incremental_state is not None and is_prefilling:
            index_mask = self.get_index_mask(
                x, x.size(1) - padding_len, x.size(1)
            )

        rel_pos = self.build_rel_pos(x, start_pos)

        # 顺序经过 L/2 个 self 层
        for idx, layer in enumerate(self.layers):
            if incremental_state is not None:
                if idx not in incremental_state:
                    incremental_state[idx] = {}
                if is_prefilling:
                    incremental_state[idx]["index_mask"] = index_mask

            x = layer(
                x,
                start_pos=start_pos,
                rel_pos=rel_pos,
                incremental_state=incremental_state[idx]
                if incremental_state is not None else None,
                is_prefilling=is_prefilling,
            )

        # 去掉 prefill 时为了 chunk 对齐补的 padding
        x = x[:, :x.size(1) - padding_len, :]
        return x

class DecoderLayer(nn.Module):
    def __init__(
        self,
        args,
        is_cross_layer=False
    ):
        super().__init__()
        self.args = args
        self.is_cross_layer = is_cross_layer

        # self 层：根据配置选择 gRet 或 SWA
        if is_cross_layer:
            self.mixer = CrossAttention(args)
        elif args.sliding_window is not None:
            self.mixer = SlidingWindowAttention(args)
        else:
            self.mixer = GateRetention(args)

        self.mixer_layer_norm = RMSNorm(
            args.dim,
            eps=args.norm_eps,
        )

        self.ffn = FeedForwardNetwork(
            args.dim,
            args.hidden_dim,
            args.load_checkpoint,
        )

        self.final_layer_norm = RMSNorm(
            args.dim,
            eps=args.norm_eps,
        )

    def forward(
        self,
        x,
        start_pos=0,
        key=None,
        value=None,
        rel_pos=None,
        incremental_state=None,
        is_prefilling=False,
    ):
        residual = x

        # 1) Mixer 前的 RMSNorm
        x = self.mixer_layer_norm(x)

        if self.is_cross_layer:
            # cross 层：K/V 由外层 CrossDecoder 传入
            x = self.mixer(
                x,
                key,
                value,
                rel_pos=rel_pos,
            )
        elif self.args.sliding_window is not None:
            # self 层：sliding-window attention
            x = self.mixer(
                x,
                rel_pos=rel_pos,
                start_pos=start_pos,
                incremental_state=incremental_state,
            )
        else:
            # self 层：gated retention
            x = self.mixer(
                x,
                rel_pos=rel_pos,
                incremental_state=incremental_state,
                is_prefilling=is_prefilling,
            )

        # 2) Mixer residual
        x = x + residual
        residual = x

        # 3) FFN 前的 RMSNorm
        x = self.final_layer_norm(x)
        x = self.ffn(x)

        # 4) FFN residual
        x = x + residual
        return x

def recurrent_gate_retention(q, k, v, g, incremental_state):
    bsz, num_head, _, key_dim = q.shape
    k *= key_dim ** -0.5

    # g 是 log decay，取 exp 后得到 γ_n
    g = g.view(bsz, num_head, 1, 1).float().exp()

    # 当前 token 的 K_n^T V_n
    kv = k.transpose(-1, -2) * v          # [B,H,Dh,Dh]

    # 取出上一步的 S_{n-1}，加上 γ_n * S_{n-1}
    if "last_hidden_state" in incremental_state:
        prev_kv = incremental_state["last_hidden_state"]
        kv += prev_kv * g.to(prev_kv.dtype)  # S_n = γ_n S_{n-1} + K_n^T V_n

    # 写回 S_n
    incremental_state["last_hidden_state"] = kv

    # O_n = Q_n S_n
    o = q @ kv                              # [B,H,S,Dh]
    return o

class SlidingWindowAttention(nn.Module):
    def __init__(self, args):
        super().__init__()
        self.args = args
        self.embed_dim = args.dim
        self.num_heads = args.n_self_heads // args.model_parallel_size
        self.window_size = args.sliding_window
        self.head_dim = args.dim // args.n_self_heads

        self.q_proj = ColumnParallelLinear(
            args.dim, args.dim, bias=False,
            gather_output=False, init_method=init_method,
        )
        self.k_proj = ColumnParallelLinear(
            args.dim, args.dim, bias=False,
            gather_output=False, init_method=init_method,
        )
        self.v_proj = ColumnParallelLinear(
            args.dim, args.dim, bias=False,
            gather_output=False, init_method=init_method,
        )
        self.out_proj = RowParallelLinear(
            args.dim, args.dim, bias=False,
            input_is_parallel=True, init_method=init_method,
        )

    def forward(self, x, rel_pos, start_pos=0, incremental_state=None):
        bsz, tgt_len, embed_dim = x.size()
        src_len = tgt_len

        q = self.q_proj(x)
        k = self.k_proj(x)
        v = self.v_proj(x)

        q = q.view(bsz, tgt_len, self.num_heads, self.head_dim)
        k = k.view(bsz, src_len, self.num_heads, self.head_dim)
        v = v.view(bsz, src_len, self.num_heads, self.head_dim)

        q = apply_rotary_emb(q, *rel_pos, interleaved=True)
        k = apply_rotary_emb(k, *rel_pos, interleaved=True)

        if incremental_state is not None:
            if "prev_key" not in incremental_state:
                incremental_state["prev_key"] = torch.empty(
                    self.args.max_batch_size,
                    self.window_size,
                    self.num_heads,
                    self.head_dim,
                    device=x.device,
                    dtype=x.dtype,
                )
                incremental_state["prev_value"] = torch.empty(
                    self.args.max_batch_size,
                    self.window_size,
                    self.num_heads,
                    self.head_dim,
                    device=x.device,
                    dtype=x.dtype,
                )

            key = torch.cat(
                [incremental_state["prev_key"][:bsz, :start_pos], k],
                dim=1,
            )
            value = torch.cat(
                [incremental_state["prev_value"][:bsz, :start_pos], v],
                dim=1,
            )

            if key.shape[1] > self.window_size:
                incremental_state["prev_key"][:bsz] = key[:, -self.window_size:]
                incremental_state["prev_value"][:bsz] = value[:, -self.window_size:]
            else:
                incremental_state["prev_key"][
                    :bsz, start_pos:start_pos + tgt_len
                ] = k
                incremental_state["prev_value"][
                    :bsz, start_pos:start_pos + tgt_len
                ] = v
        else:
            key, value = k, v

        attn = flash_attn_func(
            q, key, value,
            causal=True,
            window_size=(self.window_size - 1, 0),
        )
        attn = attn.reshape(
            bsz, tgt_len, self.head_dim * self.num_heads
        )

        attn = self.out_proj(attn)
        return attn

Cross-Decoder 与共享 KV

YOCO 的“只缓存一次”发生在 self-decoder 与 cross-decoder 的交界处： X¹³ 经过一次 RMSNorm 和一组 K/V 投影，得到全局 K̂/V̂；13 个 cross 层只计算各自的 Q。

K̂ = LN(X13) WK V̂ = LN(X13) WV
Q̂l = LN(Xl) WQl Yl = Attn(Q̂l, K̂, V̂) + Xl
l = 14 … 26。K̂/V̂ 与层号 l 无关；Q̂ 才是 layer-specific。
共享侧

K/V projector 只存在一份

W_K, W_V : [3072, 1024]
K̂/V̂ : [B,S,8,128]
整个 CrossDecoder 容器只建这一组投影。

独立侧

每个 cross 层保留自己的 Q / out_proj / FFN

Q_l : [B,S,24,128]
out_proj : [3072,3072]
只有 Q 是 layer-specific；K/V 是全局对象。

GQA 的物理形状

论文为了简洁写成 W_K,W_V ∈ R^{D×D}，代码实际使用 GQA： 24 个 Q head 对应 8 个 KV head。

表 4. Cross-decoder 中 K/V、Q 与 GQA 物理 cache 的形状。

张量逻辑/物理形状说明
W_K / W_V[3072, 8×128] = [3072,1024]不是 [3072,3072]
K̂ / V̂[B,S,8,128]物理 cache；不复制到 24 head
Q_l[B,S,24,128]每层独立
attention 输出[B,S,24,128]flash-attn 内部做 GQA 广播
global cache[B,S_total,8,128]K/V 各一份
常见误解

“共享 KV”不是“cross 层里没有 K/V 投影代码”。准确地说： K/V 投影代码只存在于 CrossDecoder 容器上， 13 个 cross 层只接收并使用它算出的同一个 key/value。

prefill 提前退出的注意点：

  • 返回的 [B,1,D] 是代码里的占位输出，不是完整 [B,S,D] logits。
  • 返回前 K/V 已经写入了 prev_key/prev_value；因此“跳过 cross”不会丢掉 global KV。
  • 实际 serving 还需要在后端补上 logits 计算/采样路径，不能把占位张量直接当输出。

class DecoderLayer(nn.Module):
    def __init__(self, args, is_cross_layer=False):
        super().__init__()
        self.args = args
        self.is_cross_layer = is_cross_layer

        if is_cross_layer:
            self.mixer = CrossAttention(args)       # ***cross: 只有 Q/out***
        elif args.sliding_window is not None:
            self.mixer = SlidingWindowAttention(args)
        else:
            self.mixer = GateRetention(args)        # ***self: Q/K/V/G 全套***

        self.mixer_layer_norm = RMSNorm(args.dim, eps=args.norm_eps)
        self.ffn = FeedForwardNetwork(
            args.dim, args.hidden_dim, args.load_checkpoint
        )
        self.final_layer_norm = RMSNorm(args.dim, eps=args.norm_eps)

    def forward(self, x, start_pos=0, key=None, value=None,
                rel_pos=None, incremental_state=None, is_prefilling=False):
        residual = x
        x = self.mixer_layer_norm(x)

        if self.is_cross_layer:
            # 注意：这里传入的 key/value 来自外层 CrossDecoder
            x = self.mixer(x, key, value, rel_pos=rel_pos)
        elif self.args.sliding_window is not None:
            x = self.mixer(
                x, rel_pos=rel_pos, start_pos=start_pos,
                incremental_state=incremental_state,
            )
        else:
            x = self.mixer(
                x, rel_pos=rel_pos,
                incremental_state=incremental_state,
                is_prefilling=is_prefilling,
            )

        x = x + residual
        residual = x
        x = self.final_layer_norm(x)
        x = self.ffn(x)
        x = x + residual
        return x

class CrossAttention(nn.Module):
    def __init__(self, args):
        super().__init__()
        self.embed_dim = args.dim
        self.num_heads = args.n_attn_heads // args.model_parallel_size
        self.num_kv_heads = args.n_attn_kv_heads // args.model_parallel_size
        self.head_dim = args.dim // args.n_attn_heads

        self.q_proj = ColumnParallelLinear(
            args.dim, args.dim, bias=False,
            gather_output=False, init_method=init_method,
        )
        self.out_proj = RowParallelLinear(
            args.dim, args.dim, bias=False,
            input_is_parallel=True, init_method=init_method,
        )

    def forward(self, x, key, value, rel_pos):
        bsz, tgt_len, _ = x.size()

        q = self.q_proj(x)
        q = q.view(bsz, tgt_len, self.num_heads, self.head_dim)
        q = apply_rotary_emb(q, *rel_pos, interleaved=True)

        # key/value 是外层 CrossDecoder 传入的共享 KV
        attn = flash_attn_func(q, key, value, causal=True)
        attn = attn.view(
            bsz, tgt_len, self.head_dim * self.num_heads
        )
        attn = self.out_proj(attn)
        return attn

共享 KV 的存储逻辑

YOCO 的 cache 不是“一个统一池子”，而是三类生命周期不同的张量。 理解“谁写、谁读、是否随 S 增长”比记住总大小更重要。

写者 / 读者

CrossDecoder 容器写 K̂/V̂ 一次
13 × CrossAttention只读 K̂/V̂
13 × SelfDecoder写 gRet state / SWA
SelfDecoder 输出 X¹³K/V 的唯一输入

生命周期

global K̂/V̂随 S_total 增长；只一份
gRet state每层固定；不随 S 增长
SWA cache每层 C=128；环形覆盖
Q / FFN 激活前向临时；不缓存

cacheshape份数随 S 增长？
Cross global K̂[B, S_total, Hkv, Dh]1是，但只一份
Cross global V̂[B, S_total, Hkv, Dh]1是，但只一份
Self gRet state[B, Hself, Dh, Dh]13否，固定
Self SWA K/V[B, C, Hself, Dh]13 × 2否，固定窗口
存储层面的“only cache once”

论文的 “only cache once” 指的是 global KV：13 个 cross 层不再各存一份 [B,S,8,128]。self-decoder 仍然有自己的常数缓存（gRet state 或 SWA window）， 但它不随 S 增长，量级与 global KV 不同。

V4.1-Flash：CED 与 H20

V4.1 的 CED 可以看成 YOCO 思路的生产化变体：前 20 层是 causal encoder， 后 20 层是 decoder；两半之间的桥不是复制 H20，而是 从 H20 派生出的 decoder global KV。

核心机制

encoder 处理完整 prompt，输出最终 hidden H20； layer20 的 compressor 把 H20 投影成一份 compressed KV，并发布到 shared_attn.compress_kv； decoder 层只保留自己的 Q，读取这份共享 KV，不再各自写 global KV。

图 3. V4.1-Flash CED 的机制路径。H20 不直接进入 decoder；它先被 layer20 投影成 shared compressed KV，后续 decoder 层只读这份 cache。

执行顺序

  1. Encoder：前 20 层处理完整 prompt；layer 0–1 为 SWA-only，layer 2–19 使用 compressed KV。输出 H20。
  2. Boundary：layer20 是第一个 ratio=1 的 decoder 层，也是最后一个 kv_source_layer。它运行 compressor，把 H20 投影为 decoder 的 global KV。
  3. Publish：compressor 先产生 latent；indexer 使用未 RoPE 的 latent 计算 top-k；随后 latent 做 RoPE/量化并写入 compress_kv_cache。
  4. Consume：layer21–39 的 is_kv_source=False，不运行自己的 compressor；它们读取 shared_attn.compress_kv，并各自维护自己的 window KV。
论文 vs. HF reference

论文写的是每个 decoder 层从 H20 做独立投影 C_l = H20 · W_l^KV。 HF 的 inference/model.py 是 readable reference： 只看到 layer20 的一个 Compressor，后续层读同一份 cache，没有把每层 W_l^KV 显式展开。

CED 与 encoder 内部 KV share 的关系

在数据流上，layer20 的 H20→KV 与 encoder 内部 layer2/8/14 的 source→consumer 是同构的：都是 source 写、consumer 读。区别在于 H20 是 encoder 的最终输出， decoder 侧的 global KV 只读；CED 的价值来自“prefill 只跑 encoder + decoder 使用 H20 的 KV”， 而不是某个新的 attention 算子。

执行边界

模型结构上，decoder 层只读 H20 派生的 KV。生产执行可以把 prefill 停在 encoder； HF 的 reference forward 仍会跑完全部 40 层，因此“prefill 提前退出”属于执行层优化， 不是这份模型代码的 forward 行为。
